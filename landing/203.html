About the course

This course takes the idea of 202 AV Streaming further and turns the system into a media server for events and theatre. It is for TouchDesigner users who want to build their own media server without a large team or years of development. You build it block by block: an engine kept separate from its interface, so Ableton over OSC can drive it with or without sliders; a movie library preloaded into GPU memory, with live cameras, a Kinect gesture trigger and a movie-bin interface next to a custom slider; colour correction and grading in GLSL with an effects library; a cue and preset system; and timecode control with smooth cross-blends between movies. At the end you take the server to the venue: output to several projectors with keystone correction, NDI between machines and safety nets for a live show, and protecting your components with a TouchDesigner Pro licence.

Course aims

  • To provide an understanding of how to build a media server for events and theatre with the engine kept separate from its interface, so that the same model can be driven from sliders, OSC or other controllers.
  • To develop practical skills in building the blocks of a media server in TouchDesigner: a preloaded movie library with a clip browser and crossfades, interface controls, GLSL colour correction and effects, presets management using JSON, timecode cues, and output to several projectors for a live show.

    Programme

    Media Server Architecture (MVC Basics)

    1 video · 33 min

    Lesson 1. MVC Media Server Controls · 33 min

    In this lesson we split a TouchDesigner media server into an interface and a model, so the same model can be driven by sliders, OSC or web data. Then we control a parameter with a channel named after its path, and use it to switch one slider between two movie players.

    Video Playback

    6 videos · 2 h 42 min

    Lesson 2. Interactive Movie Playback Control · 28 min

    In this lesson we learn how TouchDesigner chooses which movie frame to show, and build a movie player that starts, restarts and loops on a button press. First we compare exports with expressions, look at frame rate and the three play modes, and separate event triggers from continuously changing data. Timer callbacks are previewed.

    Lesson 3. Building a bidirectional movie playback slider · 40 min

    In this lesson we build a movie player whose progress slider follows the playing movie and, when you drag it, takes control of the playback. Before that we look at what Python and GLSL are used for in TouchDesigner, how the Execute operators react to events, and how a script can update a Timer's length when the movie changes.

    Lesson 4. Connecting video cameras and streams; Kinect hand-raise movie trigger · 19 min

    In this lesson we bring live video into a project and use a body gesture to control a movie. We connect a webcam, a Canon camera through a local web stream, an iPhone over NDI and a Kinect Azure, then turn a raised left hand into a trigger that restarts the movie, answering a chat question.

    Lesson 5. Procedural Movie Library Management · 27 min

    In this lesson we prepare a movie library that sits in graphics memory before a performance. We list the movies of a folder, compare direct wires with Select operators for modular components, and use a Replicator to create one preloaded movie loader per file, then check the preload and memory use.

    Lesson 6. Building a movie library browser with playback · 30 min

    In this lesson we build a clip browser for the preloaded movie library. A table of each movie's name, length, rate, audio and resolution is shown in a selectable Simple Lister, and the selected row sets the timer length, plays that movie and sends it to the output. The interface stays separate from playback, so another control can replace it.

    Lesson 7. Crossfading selected movies; Building a 2D texture array · 18 min

    In this lesson we add a smooth crossfade to the movie library: the old movie stays as the previous one and fades out under a timer, with the fade bent into a curve. We also wire every generated movie into a GLSL Multi TOP prepared as a 2D texture array. A chat question about blending is answered.

    User Interfaces

    3 videos · 1 h 53 min

    Lesson 8. Building an instanced video browser with Render Pick · 44 min

    In this lesson we build a clickable movie browser from rendered 3D geometry. First we store resolution and paths in project-wide variables, then draw one instanced button per movie, each with its own video thumbnail. Render Pick turns a click into a movie choice and marks the selected button.

    Lesson 9. Building lightweight interfaces with panels and custom parameters · 26 min

    In this lesson we choose how to build a fast, usable interface for a media server. We compare custom parameters, panels, the built-in button and slider, and ready-made widgets, including how each recalls preset values, and look at an interface kept separate from the engine.

    Lesson 10. Caching slider visuals with Cache TOP; Building a standalone slider · 43 min

    In this lesson we build a custom slider that works on its own: it keeps its range, default and reset, syncs with a parameter both ways, and maps values to the preset range. Its indicator is drawn from cached images, so it costs almost no processing. We end by walking through a blend between two movies.

    Color Grading; Image Processing ; GLSL

    4 videos · 2 h 5 min

    Lesson 11. Building a LUT browser with before-and-after comparison · 31 min

    In this lesson we learn how TouchDesigner corrects colour and build a tool for trying LUT looks on video. After a tour of the colour nodes and an explanation of what a LUT is, we make a list of LUT files that applies the chosen look, with a before-and-after slider and the LUT name shown on the picture.

    Lesson 12. Building a GLSL color-correction shader; Generating UV patterns · 28 min

    In this lesson we move colour correction into a single GLSL TOP, so it stays fast as the setup grows. We learn how a pixel shader works and generate ramps and stripes from UV coordinates, then build gamma, brightness and contrast as one function with adjustable controls and separate gamma for red, green and blue.

    Lesson 13. Building HSV and YIQ saturation with temperature correction; Prototype multi-pass GLSL effects · 30 min

    In this lesson we extend the GLSL colour corrector with saturation and colour temperature. We build saturation in HSV, see why it differs from OpenColorIO, and switch to the YIQ model, which matches it and adds a temperature control. Then we outline how several passes chain correction and ShaderToy effects in one node.

    Lesson 14. Converting ShaderToy effects to GLSL TOPs; Building a selectable shader library · 37 min

    In this lesson we port ShaderToy image effects into TouchDesigner and turn them into a library you can switch between. We replace ShaderToy's mouse, resolution and image inputs, add wet and size controls, and convert four effects the same way. Then one shader node loads any effect by name from a menu.

    Preset Management

    3 videos · 1 h 43 min

    Lesson 15. Generating custom parameters from a control table · 29 min

    In this lesson we generate the controls of a component with a Python script instead of building them by hand in the editor. We describe colour controls in a table, turn each label into a valid parameter name, and create every control with its range, clamping and default. We start by packing the layer into a base component.

    Lesson 16. Building a dictionary-based preset manager · 50 min

    In this lesson we prepare the layer for saving presets and start a preset manager. We add a transform page bound to the layer, then compare keeping presets in tables with Python dictionaries stored inside a node. We build a manager that captures all controls, or one chosen page, as a named dictionary.

    Lesson 17. Saving and loading parameter presets as JSON · 24 min

    In this lesson we make presets last outside the project: the manager saves a preset to a JSON file named after the preset and the time, then loads a chosen file. Each saved value is applied back to the layer's controls by looking the control up by its name.

    Timing and Synchronisation

    3 videos · 1 h 51 min

    Lesson 18. Converting LTC timecode to frames with Script CHOP · 37 min

    In this lesson we see how TouchDesigner handles time and how to keep two machines in step. We make a repeating trigger, send LTC timecode from one TouchDesigner instance to another, and start a Script CHOP that turns the received timecode into a frame count for a cue table.

    Lesson 19. Cueing and Segmented Playback · 45 min

    In this lesson we finish the cue tool: a script reads the cue table and gives every cue its start and end pulses, elapsed frames, progress and active segment. We compare it with the timer's segments mode, then build a scene asset whose movie and title fades are driven by that progress.

    Lesson 20. Multi-projector output with Layout TOP and keystoning; Movie crossfades · 28 min

    In this lesson we finish the media server with a smoother A/B transition between two movies. Then we look at taking it to a show: keeping the interface apart from processing, sending video between machines with NDI, mapping output for several projectors, and locking a project or component before it goes to a client.

    FAQ

    How long will I have access to the lessons?

    730 days. If you need more time, write to us and we extend it.

    Why pay for the course if there are free tutorials on YouTube?

    YouTube tutorials are made to teach one specific technique, usually without a system or a methodology. We teach you to understand systematically how the logic of node architecture works, with a balance between a practical and an academic approach.

    I work on a Mac. Will the course work for me?

    Yes. More on requirements — see "What computer do I need?".

    What computer do I need?

    Windows is more efficient for this work; a Mac works too, but with limits from 3D drivers and some Nvidia-only TouchDesigner operators.
    TouchDesigner: Windows 10/11 or macOS 13+ (Apple Silicon recommended); a GPU with Vulkan 1.1 and at least 4 GB of video memory, 8 GB or more recommended.
    Ableton Live: Live 12 runs on Windows 10 (22H2) or 11, or macOS 11 or later (Intel Core i5 or Apple Silicon), with 8 GB of RAM.
    The Kinect lessons need a Windows computer and a USB 3 adapter; on a Mac they do not run.

    Is the free version of the software enough?

    TouchDesigner Non-Commercial is enough, except the part on hiding your components from clients: that needs TouchDesigner Pro.

    Is there code in the course?

    In parts: Python builds the preset manager and the timecode reader, and GLSL builds the colour-correction shaders — about 3.9 h of 10.8 h. You mostly adapt and extend ready-made code; basic GLSL and scripting knowledge helps.
